## 💡 Why This Project?

### The Pain Points of Traditional AI-Generated UI
1. **Severe "AI Slop" Aesthetic Homogenization**: Pure white backgrounds, garish purple/pink gradients, and unconstrained bubble-rounded cards lacking real design system discipline.
2. **Brittle Prompt Modification**: Altering a single shadow or color palette in a monolithic prompt often breaks the entire layout.

### Our Solution: Template Marketplace + Component Cookbook
* **Zero-Config Template Marketplace (`index.html`)**: 4 enterprise-grade product prototypes covering DevTools, Knowledge OS, Edge Ops, and Content Studio.
* **One-Click AI Prompt Replication (`Copy Prompt`)**: Every template comes with a tested, production-grade prompt recipe ready to paste into any AI Agent.
* **20 Production Design Recipes (`06_design_system_cookbook.html`)**: Extract Linear-style spotlights, VisionOS frosted glass, Magic UI rotating shimmer borders, and dynamic island navigation with one click.

## 🚀 Quick Start

### Zero-Config Standalone HTML
All prototypes are self-contained `.html` files equipped with Tailwind CSS CDN and Lucide Icons. No `npm install`, build step, or server required—double click to open in any modern browser!

### Free Deployment on GitHub Pages
1. Fork or push this repository;
2. In `Settings` -> `Pages`, choose `Deploy from a branch` (`main` / `/(root)`);
3. Your online template marketplace will be live within seconds.
